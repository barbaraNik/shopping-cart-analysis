# Исправленная версия ТЗ

## 1.Функционал корзины

---

## Т3.1. Добавление товаров в корзину

1. Пользователь может добавить в корзину от 1 до 10 единиц одного товара за одну операцию.

2. В корзине может находиться не более 5 различных товаров одновременно.

3. Суммарное количество всех товаров в корзине не может превышать 20 единиц.

4. При попытке добавить товар, которая приведет к превышению лимитов (п. 1–3), система:
   - блокирует операцию добавления
   - показывает пользователю сообщение об ошибке: "Лимит корзины превышен"

---

## Т3.2. Изменение количества товаров

1. Пользователь может изменить количество товара в корзине в диапазоне от 1 до 10 единиц для одной позиции.

2. Общее количество товаров после изменения не должно превышать 20 единиц.

3. При попытке превысить лимит система:
   - показывает сообщение: "Лимит корзины превышен"
   - сохраняет предыдущее значение количества товара

---

## Т3.3. Удаление товаров

1. Для удаления товара из корзины используется отдельная кнопка **«Удалить»** рядом с каждой позицией.

2. Изменение количества товара до 0 единиц через интерфейс изменения количества невозможно.

3. Минимально допустимое количество товара в корзине - 1 единица.

---

## Т3.4. Ценообразование

1. Цена товара фиксируется на момент добавления товара в корзину.

2. Цена сохраняется неизменной в течение всей пользовательской сессии.

3. При изменении цены товара в каталоге цена в корзине текущих пользователей автоматически не обновляется.

4. При начале новой пользовательской сессии:
   - цены в корзине синхронизируются с актуальными ценами каталога
   - пользователю отображается уведомление об изменении цен, если такие изменения произошли (индикатором цвета или какой-либо графикой)

---

## Т3.5. Отображение корзины

На странице корзины отображаются:

- список товаров с наименованиями
- количество единиц каждого товара
- цена за единицу товара
- общая стоимость позиции: количество × цена
- итоговая сумма всех товаров в корзине
- изменение цен (если это произошло)

---

## Т3.6. Рекламные материалы

1. В корзине может отображаться блок рекламы сопутствующих товаров 

2. Рекламный блок обновляется:
   - ежедневно в 09:00
   - ежедневно в 18:00
   - по московскому времени (UTC+3)
   - только в будние дни (понедельник–пятница)

3. В выходные дни (суббота–воскресенье) отображается последняя актуальная версия рекламного блока

---

## Т3.7. Уведомления и сообщения

1. При превышении ограничений корзины система:
   - показывает пользователю соответствующее уведомление
   - не выполняет операцию

2. Тексты сообщений:

- "Лимит корзины превышен: можно добавить не более х единиц этого товара"

- "Лимит корзины превышен: максимум 5 различных товаров"

- "Лимит корзины превышен: общее количество не может превышать 20 единиц"
